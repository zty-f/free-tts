# 04 · 连接与日常使用

前提：[创建了 Speech F0](azure-f0-setup.md)，并已 [启动本地工具](local-setup.md)。

## 第一次连接

1. 打开 [本地工作台](http://127.0.0.1:4318)，点击「连接设置」。
2. 服务区域填写 Azure 页面显示的代码，例如 `eastasia`。不要填中文区域名或完整网址。
3. Azure 密钥填写本资源的 KEY 1 或 KEY 2，不是登录密码、资源名称或订阅 ID。
4. 点击「保存并连接」，等待显示「连接正常」，音色选择器会加载本区域的普通 Neural 音色。
5. 再去 Azure 资源概览确认定价层为 F0。项目不使用管理权限，无法仅凭语音密钥验证资源定价层。

更改区域后密钥也必须匹配对应资源。两个不同资源的密钥与区域混搭通常会验证失败。

## 生成第一段语音

1. 语言选择中文（中国），音色先试晓晓或云希，具体可用性以列表为准。
2. 语速和音调先保持默认。
3. 输入：`你好，这是 free-tts 的第一次语音合成测试。`
4. 点击「生成语音」，等待完成。
5. 在播放器点击播放，听清楚后点击「下载 MP3」。

**完成标准：下载文件有声音、文字完整，MP3 可以在本机播放器打开。** 点击生成会调用你的 Azure 服务；本机缓存命中除外。

## 音色、速度和计数

- 先选语言再选音色。「刷新音色」重新取得当前资源可用音色。
- 语速支持 0.5× 至 2×；音调支持 -20% 至 +20%。
- 输入框计数是 Unicode 字符数，本工具每次最多 3,000 个。
- 正文预计计费字符按汉字约 2、其他码点约 1 计算，不含 SSML 标记和其他特殊计费细节，是提示值。
- 超过粗估 8 分钟时禁用生成，建议分段。估算按中文约 250 字/分钟、其他文字约 140 词/分钟再结合语速，实际不同音色会有差异。
- Azure 实时合成有单次 10 分钟上限。长文请分成较短段落生成；本版不自动分段或合并。

## 缓存和最近生成

生成成功后，音频会保存在本机 `.local/audio/`，最多保留最近 20 段。

同一密钥、区域、完整文字、音色、语速和音调命中已有缓存时，再点生成不会请求 Azure；页面会明确提示复用本机音频。更改文字、参数、密钥或区域后会形成新的请求。

- 刷新网页或重启工具后，可以在「最近生成」试听或下载。
- 播放或下载已有音频不重复合成。
- 「清理本机音频」会删除工具缓存和记录，已另外下载到“下载”文件夹的文件不受影响。
- 清理或被自动淘汰后再次生成需要重新请求 Azure，也可能再次消耗额度。

## 密钥和隐私

密钥保存在项目目录 `.local/config.json`，这是本机明文配置。界面会清空刚输入的密钥，不把已保存密钥返回页面。更换密钥时输入新的完整值；只修改区域而留空密钥则沿用已有值。

「清除本机密钥」只删除本机连接配置，不删除 Azure 资源，也不清理已经缓存的音频。若卡号或密钥被泄露，不能只清浏览器，应在相应服务中处理或轮换。

浏览器会在当前网站保存正文草稿、语言、音色和参数。点击「清空」清除当前草稿；要彻底移除站点数据，可在浏览器设置中清除此本地站点的存储。项目不发送遥测，生成文字会发往 Microsoft Azure，仍受 Azure 自身的数据处理政策约束。
