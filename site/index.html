你可能还想知道

需要购买服务器吗？

不需要。打开在线工作台即可使用，无需安装 Node.js。网站由 GitHub Pages 托管，浏览器直接连接你自己的 Azure Speech；本地版仍可下载使用。

200 美元赠金和每月免费额度是一回事吗？

不是。200 美元是符合资格的新账号前 30 天试用赠金；F0 是 Speech 资源的月度免费层。试用到期后通常需升级订阅才能继续使用，资源保持 F0。阅读订阅到期说明。

可以直接在这个网站生成语音吗？

可以。打开在线工作台，填写自己的 Azure 密钥和区域，连接后即可合成、试听和下载 MP3。密钥仅在本页内存中使用，不写入浏览器存储。

免费额度每月都会有吗？

在有效 Azure 订阅和符合条件的 F0 资源下，每月按该层规则提供免费额度，不结转。以 Azure 当前政策和资源门户为准。查看官方定价。
