# 03 · 在线工作台（免安装）

目标：打开网页，使用自己的 Azure Speech 合成、试听并下载 MP3。无需安装 Node.js、下载源码或购买服务器。需要能联网访问 Azure 的现代浏览器，例如近期版本的 Chrome、Edge、Safari 或 Firefox；具体兼容情况见验证记录。

## 准备密钥与区域

先按 [注册教程](azure-registration.md) 激活 Azure 订阅，再按 [Speech F0 教程](azure-f0-setup.md) 创建资源。已有资源可以直接使用。

1. 在 [Azure 控制台](https://portal.azure.com/) 打开自己的 Speech 资源。
2. 确认资源的定价层是 **Free F0**。本项目不能通过合成密钥验证你的定价层。
3. 打开「资源管理 → 密钥和终结点」，复制 KEY 1 或 KEY 2。
4. 记下区域代码，例如 `eastasia`。必须使用该资源实际的区域，不填中文区域名、完整 Endpoint、订阅 ID 或资源名称。

## 连接与合成

1. 打开 [在线工作台](https://zty-f.github.io/free-tts/workbench/)。GitHub Pages 地址会按当前域名配置跳转到网站。
2. 填入区域代码和完整密钥，点击「连接 Azure」。连接会从 Azure 获取该区域的普通 GA Neural 音色，不会生成音频。
3. 显示「已连接 · 仅本页」后，选择语言与音色，先保留默认语速和音调。
4. 输入一句短文本，例如 `你好，这是我的第一段在线语音。`，点击「生成语音」。
5. 等待完成后，在结果播放器点击播放，再点击「下载 MP3」。部分手机浏览器可能通过分享菜单保存文件。

成功标准：显示合成结果、播放器可以试听、下载的 MP3 能在播放器中打开。连接成功只证明资源可访问，不证明它是 F0。

## 密钥只在当前页面保存

- 密钥只在当前页面的 JavaScript 内存中使用；连接提交后立即清空密码输入框。
- 网页不主动把密钥写入 localStorage、sessionStorage、Cookie、地址栏或项目后端，也没有账号同步或「记住密钥」选项。
- 刷新、离开或关闭页面后需要重新填写；通过浏览器后退恢复的页面也会清除连接。
- 「断开并清除密钥」会清除当前连接，已完成的音频仍可下载。不会删除 Azure 资源，也不会使 Azure 上的旧密钥失效。
- 点击「取消并断开」会取消浏览器请求并清除密钥；取消前 Azure 已处理的文字仍可能计入用量。
- 在线版不主动持久保存正文或音频，只显示当前结果；下一次成功生成会替换它，刷新前请下载。

网页代码需要读取你输入的密钥，浏览器扩展、同源恶意脚本或受控设备可能访问页面数据；内存保存不是加密保险箱。仅在信任的官方项目网站或自行部署的版本填写密钥。浏览器自己的密码管理器行为不由网页保证。

## 数据经过哪里

浏览器 → 你选择区域的 Microsoft Azure Speech → 浏览器播放器与下载。

网站由 GitHub Pages 托管静态文件。语音请求不经过项目转发服务器；通过 HTTPS 请求头发送密钥，正文在生成时发送给 Azure。当前使用官方 REST 接口，没有引入第三方 SDK、远程字体或统计脚本。[官方接口说明](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech)

## 额度与限制

- F0 额度属于你的 Azure 资源，在线版与本地版共用该资源的用量，不会各送一份。
- 每次点击「生成语音」都会请求 Azure；在线版不提供去重缓存、不自动重试。试听或下载已有结果不会再次合成。
- 每次最多 3,000 个输入字符；按语速粗估超过 8 分钟时需要分段。正文计费字符提示不是月度剩余额度。
- 普通 Neural 音色、语速和音调规则与 [日常使用说明](usage.md) 一致。

## 连接失败怎么办

401 通常是密钥和区域不匹配；403 检查资源状态与网络限制；429 可能是频率、音色容量或配额。网络错误也可能来自浏览器代理、扩展或跨域限制，不能直接认定是额度耗尽。

浏览器使用系统或浏览器的网络设置，不能读取启动终端中的 HTTPS_PROXY。若浏览器无法访问 Azure，请先处理浏览器网络，或选择 [本地版](local-setup.md) 通过本机 curl 连接。错误详情见 [故障排查](troubleshooting.md)。

## 自己部署到 GitHub Pages

Fork [项目仓库](https://github.com/zty-f/free-tts)，在 Settings → Pages 将 Source 设为 GitHub Actions，并启用仓库工作流。推送 main 后，`pages.yml` 执行测试并构建 `_site/`，再发布为静态网站。

默认仓库名为 `free-tts`，构建子路径为 `/free-tts/`。若改名，请在 Pages 工作流的构建步骤设置 `SITE_BASE_PATH=/你的仓库名/`；使用独立域名根路径则设为 `/`。首页和教程中指向本项目官网的绝对链接可按需改成自己的地址。无需配置 Azure 密钥到 GitHub Secrets 或仓库文件。
