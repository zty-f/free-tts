# 官方入口链接

核对日期：2026-10-22。以下均为对应厂商官网。Azure 门户的 # 后面是前端导航路由，HTTP 200 或能打开门户不证明特定账号一定能创建 F0；请按教程确认资源定价层。

## 注册与资源

- [Azure 免费账号注册](https://azure.microsoft.com/free/)
- [Azure 免费账号条件与注册要求](https://azure.microsoft.com/en-us/pricing/purchase-options/azure-account)
- [Azure 控制台](https://portal.azure.com/)
- [直接创建 Speech 资源](https://portal.azure.com/#create/Microsoft.CognitiveServicesSpeechServices)
- [Azure 创建资源入口](https://portal.azure.com/#create/hub)
- [微软账号管理](https://account.microsoft.com/)
- [Speech Studio 官方网页](https://speech.microsoft.com/portal)

Speech 直达入口若变更，用 Azure 门户 → 创建资源 → 市场搜索 Speech / 语音 → Microsoft 发布者 → 创建，并选 F0。不要为了跟教程按钮名称一致而创建其他产品。
