你可能还想知道

需要购买服务器吗？

不需要。语音工作台在自己的电脑运行，需要 Node.js 22+ 和 curl，并联网访问 Azure。本网站使用 GitHub Pages 托管教程。

200 美元赠金和每月免费额度是一回事吗？

不是。200 美元是符合资格的新账号前 30 天试用赠金；F0 是 Speech 资源的月度免费层。试用到期后通常需升级订阅才能继续使用，资源保持 F0。阅读订阅到期说明。

可以直接在这个网站生成语音吗？

请先下载源码并在本机启动，工作台默认地址是 127.0.0.1:4318。这个在线站点提供完整教程和下载入口，不收集 Azure 密钥。

免费额度每月都会有吗？

在有效 Azure 订阅和符合条件的 F0 资源下，每月按该层规则提供免费额度，不结转。以 Azure 当前政策和资源门户为准。查看官方定价。
