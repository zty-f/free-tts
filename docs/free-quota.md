# 免费额度怎么算

规则核对：2026-10-22。费用最终以你自己的 Azure 资源、订阅和官方当期计费规则为准。

## 50 万是计费字符

Azure Speech **Free F0** 目前为普通 Neural 文字转语音提供每月 50 万计费字符，免费额度按周期更新，不累积到下个月。它不是“每天 50 万”，也不是项目赠送的公共余额。

微软明确说明：每个汉字按 2 个计费字符计，包括日语汉字、韩语汉字等。英文字母、标点、空白及部分 SSML 内容也计入规则。因此，不要把每月 50 万计费字符写成“50 万汉字”。

来源：[官方 Speech 定价](https://azure.microsoft.com/en-us/pricing/details/speech/) · [官方计费字符定义](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/text-to-speech#billable-characters)。

## 对个人使用意味着什么

| 每月场景 | 汉字正文量 | 仅汉字部分预计用量 |
| --- | --- | --- |
| 每天 1,000 字，30 天 | 30,000 汉字 | 60,000 计费字符 |
| 每天 2,000 字，30 天 | 60,000 汉字 | 120,000 计费字符 |
| 每天 5,000 字，30 天 | 150,000 汉字 | 300,000 计费字符 |

上表是算术示例，未计其他字符、重做和失败请求可能产生的用量。它说明很多个人轻中度场景可能够用，不代表所有需求都够，也不能承诺永久免费政策永不改变。

## 免费层和付费层

- F0：固定免费配额，达到限制后可能无法继续合成，等待额度恢复或自行决定是否更改方案。本工具不会自动升级资源。
- S0：按对应价格计费；不能套用“每月先免费 50 万，超出再付费”的 F0 逻辑。
- 注册时的 200 美元是另一个限时试用权益，不是 F0 每月配额来源。
- 多个工具调用同一个资源会共享其配额，不能按每个客户端分别得到 50 万。

## 请求限制不等于月度额度

Azure 当前 F0 实时 TTS 还有调用频率限制，文档列出每 60 秒最多 20 次事务，单次生成音频最长 10 分钟。429 也可能是某个区域音色容量不足，并不必然表示月度额度耗尽。

本工具每次 3,000 输入字符、同时一个生成任务及粗估 8 分钟保护是应用侧限制；它们不是 Azure 的月度计数。[官方配额说明](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/speech-services-quotas-and-limits)。

## 查看实际使用量

从 [Azure 控制台](https://portal.azure.com/) 打开自己的资源及订阅，查看相应可用的指标、免费服务使用量和成本分析。不同账号和订阅可见的界面不同，账单数据也可能延迟。

参考 [微软免费服务用量查询](https://learn.microsoft.com/en-us/azure/cost-management-billing/manage/check-free-service-usage)。free-tts 的正文计数不读取 Azure 真实剩余配额，也不构成扣费保证。

为了节省额度，先用短文本调好声音，再生成全文；优先重用本机缓存，完成后保存 MP3，避免相同内容反复调用。
