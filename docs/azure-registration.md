# 01 · 注册 Azure 账号

目标：拥有可用的 Azure 订阅。此时还不需要安装 GitHub 项目，也不需要把任何密钥发给别人。

## 准备材料

- 一个自己的微软账号；已有 Outlook、Hotmail 等微软账号可直接登录。注册页若提供 GitHub 登录也可按页面操作。
- 可接收验证码的手机号。
- Azure 当前地区支持的信用卡或非预付费借记卡。卡种、地区及风控审核以注册页面为准。
- 真实的姓名、国家地区和银行账单地址。不要为通过注册填写不属于自己的地区或地址。

本教程对接 Azure 国际版 `portal.azure.com`，当前项目的接口域名是 `speech.microsoft.com`。世纪互联运营的 Azure 中国是独立环境，不能把中国区密钥直接用于本项目。

官方：[账号注册要求与免费账号说明](https://azure.microsoft.com/en-us/pricing/purchase-options/azure-account)。

## 第一步：打开官方注册入口

1. 打开 [Azure 免费账号注册](https://azure.microsoft.com/free/)。
2. 选择「免费开始 / Start free」或页面中的免费试用入口。
3. 用自己的微软账号登录；没有账号就在登录页面创建。
4. 填写账户资料，国家/地区与自己的账单资料保持一致。

免费试用一般面向符合条件的新用户。已有订阅的用户不必反复注册，可直接查看自己订阅中是否能创建 F0 资源。

## 第二步：手机和银行卡验证

1. 按页面指示验证手机号，填写短信或语音验证码。
2. 填写持卡人姓名、卡号、有效期、安全码及账单地址。
3. 自己阅读并确认注册条款，完成提交。

**只在微软官方注册页面填写这些资料。不要提交到 free-tts，也不要截图暴露给他人。**

银行可能出现约 1 美元或等值的小额预授权，用于检查卡片。它不是语音套餐费用；临时冻结的解除时间以微软和发卡行为准。收到小额交易通知也不代表 Azure 账号已经开通，最后仍要看注册结果。

## 第三步：确认注册成功

1. 打开 [Azure 控制台](https://portal.azure.com/)。
2. 在顶部搜索「订阅 / Subscriptions」，打开自己的订阅，确认状态为「已启用 / Active」。
3. 新用户若开通免费试用，首页可能显示 200 美元剩余额度；它是限时试用赠金，不是自己充值了 200 美元。
4. 记下试用截止日期，后面阅读 [30 天后怎么办](subscription.md)。

**成功标志：有处于可用状态的订阅。只登录微软账号、能打开门户，还不等于拥有可用订阅。**

## 失败时怎么处理

| 现象 | 建议操作 |
| --- | --- |
| 安全码/CVV 报错 | 重新核对卡面安全码和有效期；信息正确时向银行询问交易拒绝原因 |
| 小额验证失败 | 查询是否支持境外线上交易；不要凭交易金额判断卡片一定可用 |
| 不接受银行卡 | 核对地区和卡种，虚拟卡及预付卡可能不被接受 |
| 免费试用不符合资格 | 核对是否曾使用过试用；不要靠重复账号规避审核 |
| 登录后没有订阅 | 在门户检查是否注册流程未完成，或目录/账号选错 |

参考 [微软注册故障排查](https://learn.microsoft.com/en-us/azure/cost-management-billing/troubleshoot-subscription/troubleshoot-azure-sign-up)；持续失败请联系微软支持或发卡行，不需要向项目维护者提供卡号、CVV 或验证码。
