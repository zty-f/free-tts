# 本地验证记录

日期：2026-10-22。此文件只记录实际完成的验证，不证明其他账号一定注册成功、一定有 F0，或其他操作系统已通过实机测试。

## 当前环境与结果

- 实机平台：macOS，Node.js v22.22.3，系统 curl 8.7.1。
- 环境自检通过；通用 shell 与 macOS 启动文件语法检查通过。
- 已有同版服务运行时，重复启动能识别并复用本机服务。
- 本机自动化检查通过，覆盖参数验证、XML 转义、计数、凭据保存及不回显、跨站保护、音色过滤、并发限制、音频缓存及清理、重启恢复、教程渲染和白名单打包。
- 所有 Markdown 本地链接和 9 个浏览器教程页检查通过；首次使用页、Speech F0 教程在浏览器中查看过桌面和窄窗口排版。
- 真实 Azure 测试：使用用户已在本机配置的资源，读取音色列表后，将“你好，这是免费语音测试。”合成为 MP3。未输出密钥、未更改资源定价层。
- 返回音频 17,712 字节，MP3、24 kHz、单声道、约 2.952 秒，ffmpeg 解码检查通过；浏览器播放器能读取完整时长并进入可播放状态。
- 同样的请求第二次命中本机缓存；重新打开网页后可从最近生成恢复音频，未再次合成。
- 本机接口连通和成功合成不能用于验证 Azure 资源定价层。F0 必须由资源所有者在 Azure 门户中确认。
